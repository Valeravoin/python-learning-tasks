# Input/Output Basics Module

Набор базовых задач на ввод и вывод данных в Python. Модуль покрывает основы: `input()`, `print()`, целочисленная арифметика, работа со строками и числами, форматирование вывода.

## Задачи в этом модуле

1. **Звёздный прямоугольник** (`star_rectangle.py`)
   - Рисование прямоугольника из символов.
   - Практика: умножение строк, циклы, конкатенация.

2. **Квадрат суммы vs Сумма квадратов** (`squares_sum_vs_sum_squares.py`)
   - Сравнение двух математических выражений.
   - Практика: f-строки, промежуточные переменные, читаемость.

3. **Большое число** (`big_number_power_sum.py`)
   - Вычисление `a**b + c**d` с большими числами.
   - Практика: большие целые числа в Python, избегание перекрытия встроенных имён.

4. **Размножение n-ок** (`n_nn_nnn_sum.py`)
   - Сумма `n + nn + nnn`.
   - Практика: преобразование типов, умножение строк.

## Как запустить

В терминале перейди в папку `input_output_basics` и запусти любую задачу:

```bash
cd input_output_basics
python star_rectangle.py
python squares_sum_vs_sum_squares.py
python big_number_power_sum.py
python n_nn_nnn_sum.py
