# 🐍 Python Learning Portfolio

Это мой учебный репозиторий: здесь я собираю задачи, которые решаю, пока учусь на Django-разработчика и готовлюсь к фрилансу.  

Я не просто «прошёл тему», а оформляю каждую задачу как мини-проект: с понятными именами файлов, комментариями и описанием навыков. Так я тренирую не только код, но и то, как показывать работу заказчику.

---

## 📂 Структура репозитория

Сейчас здесь первый модуль — основы ввода и вывода:

- `input_output_basics/` — папка с задачами по `input()` и `print()`.
  - `star_rectangle.py` — рисование прямоугольника из символов.
  - `squares_sum_vs_sum_squares.py` — сравнение квадрата суммы и суммы квадратов.
  - `big_number_power_sum.py` — работа с большими числами (Python поддерживает их «из коробки»).
  - `n_nn_nnn_sum.py` — сумма `n + nn + nnn` через преобразование типов.

Дальше буду добавлять новые модули: списки, строки, валидацию, мини-проекты.

---

## 💪 Что я прокачиваю в этом репозитории

- ✅ **Базовые операции:** `input()`, `print()`, переменные, целочисленная арифметика.
- ✅ **Работа со строками:** умножение строк, конкатенация, f-строки.
- ✅ **Преобразование типов:** `int()`, `str()`, понимание разницы между числами и строками.
- ✅ **Чистота кода:** понятные имена переменных, отсутствие дублирования, следование PEP 8.
- ✅ **Git и структура проекта:** коммиты с понятными сообщениями, `.gitignore`, README для каждого модуля.

Эти навыки — база для Django: валидация форм, обработка ввода, вывод данных, работа с типами.
