## 🗺️ Карта моего прогресса

Здесь я не просто пишу код, а строю фундамент для серьёзной разработки. Каждый модуль — это прокачка конкретного навыка, который потом пригодится в крупных проектах.

### 🧱 Базовые модули

| Модуль | Что прокачал | Как пригодится в серьёзной разработке |
| :--- | :--- | :--- |
| `input_output_basics/` | Ввод/вывод, типы данных, работа со строками и числами | Обработка пользовательского ввода, парсинг данных, подготовка API-запросов |
| `conditional_operators/` | Условная логика (`if/elif/else`), валидация, цепочки сравнений, `abs()` | Проверка данных в бизнес-логике, валидация форм, правила доступа, обработка ошибок |
| `data_types_basics/` | Типы `int`/`float`, встроенные функции `min/max/abs`, извлечение и сортировка цифр | Валидация чисел в формах, расчёты в бизнес-логике, обработка финансовых/температурных/метрических данных, подготовка данных для API |
| `loops_basics/` | Циклы `for`/`while`, накопление результатов, поиск максимума, ревью и отладка чужого кода | Обработка списков пользователей, пагинация, генерация отчётов, валидация по списку кодов в боте, чтение и правка legacy-кода в Django-проектах |
| `strings_basics/` | Строковые методы (`replace`, `find`, `rfind`), срезы, индексация, сборка строк, обработка граничных случаев | Валидация кодов и промокодов в боте, очистка ввода пользователя, парсинг сообщений, форматирование ответов, обработка URL и заголовков в Django |
| `lists_and_strings/` | Работа со списками: создание, заполнение через цикл и `append`, индексация, шаг в `range`, списочные выражения. Методы строк: `split()`, `join()`, срезы, проверка символов (`isdigit`), условная валидация по позициям. Использование `sum()` для агрегации. | Валидация кодов и телефонных номеров в чат-боте, парсинг пользовательского ввода (разбиение по разделителям), формирование отчётов и логов (сборка строк), обработка списков заказов/товаров, расчёт метрик (суммы, количества). В Django — подготовка данных для шаблонов и валидация форм. |

> 💡 **Почему это важно:** Например, задача «Girls only» (проверка возраста и пола) — это та же логика валидации, которая лежит в основе форм регистрации в больших Django-проектах. А проверка хода слона — тренировка математической логики, полезной в игровых механиках, геосервисах и алгоритмических задачах.

## 📂 Структура репозитория

- `input_output_basics/` — первые шаги: ввод, вывод, типы данных.
- `conditional_operators/` — логика и валидация: условия, сравнения, математические проверки.
- `data_types_basics/` — базовые типы данных и математика: работа с числами, встроенные функции, извлечение и анализ цифр.
- `loops_basics/` — циклы и накопление результатов: перебор, условия выхода, суммирование и фильтрация данных, ревью кода.
- `strings_basics/` — работа со строками: срезы, поиск подстрок, замена и удаление символов, обработка текста.
- `lists_and_strings/` — работа со списками и строками: циклы, списочные выражения, `split`/`join`, валидация формата по символам и позициям, агрегация данных.
- - `fastapi-v1-in-memory/` — первая версия FastAPI: роутинг, фильтрация, данные в памяти.
- Каждая папка содержит:
  - отдельные файлы с задачами,
  - понятный README внутри папки,
  - аккуратную структуру и комментарии.

Такой подход помогает мне учиться не «ради галочки», а так, чтобы код было легко читать, развивать и показывать наставникам или будущим работодателям.

## 📝 Как добавлять новые темы (мой план роста)

Когда я прохожу новую тему, я обновляю этот README по шаблону:

1. Добавляю новую строку в таблицу «Карта моего прогресса».
2. Пишу 1–2 предложения, как эта тема пригодится в серьёзных проектах.
