# 🧮 Модуль: Базовые типы данных и математика

Здесь я тренируюсь осознанно выбирать типы данных (`int`, `float`), использовать встроенные математические функции и понимать, как Python работает с числами.

---

## 📋 Решённые задачи

| Задача | Суть | Навыки |
| :--- | :--- | :--- |
| **Площадь треугольника** | Расчёт площади прямоугольного треугольника через катеты | Работа с `float`, базовая формула, аккуратность вычислений |
| **451° по Фаренгейту** | Перевод температуры по формуле | Понимание порядка операций, работа с дробными числами |
| **Наименьшее и наибольшее** | Поиск min/max среди пяти чисел | Встроенные функции `min()`, `max()`, обработка нескольких вводов |
| **Абсолютная сумма** | Сумма модулей пяти чисел | Функция `abs()`, работа с отрицательными значениями |
| **Интересное число** | Проверка условия на цифры трёхзначного числа | Извлечение цифр, сортировка списка, логика «мин/сред/макс» |

---

## 💪 Что я прокачал в этом модуле

- ✅ **Осознанный выбор типа:** понимаю, когда нужен `int`, а когда `float`.
- ✅ **Математические функции:** уверенно использую `abs()`, `min()`, `max()`.
- ✅ **Работа с цифрами числа:** извлечение разрядов через деление и остаток, сортировка для поиска «средней» цифры.
- ✅ **Чистота кода:** аккуратные имена переменных, отсутствие лишних запятых и опечаток.
- ✅ **Связь с реальными задачами:** эти навыки пригодятся для валидации чисел в ботах, расчётов в Django, обработки финансовых и температурных данных.
