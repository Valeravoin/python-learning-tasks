# 🔤 Модуль: Работа со строками в Python

Здесь я тренируюсь уверенно работать со строками: индексация, срезы, методы строк и поиск подстрок. Это база для валидации ввода, парсинга сообщений в ботах и обработки текста в Django.

---

## 📋 Решённые задачи

| Задача | Суть | Навыки |
| :--- | :--- | :--- |
| **Каждый третий** | Удалить символы с индексами 0, 3, 6… | Индексация, цикл, сборка строки |
| **Замени меня полностью** | Заменить все «1» на «one» | Метод `str.replace`, работа с подстроками |
| **Удали меня полностью** | Удалить все «@» | `replace` как способ удаления символов |
| **Второе вхождение** | Найти индекс второго «f», обработать крайние случаи | Методы `find`, логика граничных условий |
| **Переворот** | Перевернуть часть строки между первым и последним «h» | Срезы, `find` + `rfind`, конкатенация строк |

---

## 💪 Что я прокачал в этом модуле

- ✅ **Индексация и срезы:** уверенно использую `s[i]`, `s[start:end]`, `s[::-1]` для переворота.
- ✅ **Методы строк:** `replace`, `find`, `rfind` — знаю, когда какой применять.
- ✅ **Обработка граничных случаев:** понимаю, как работать с `-1` от `find` и правильно интерпретировать отсутствие символа.
- ✅ **Сборка результата:** вместо «печатать посимвольно» собираю итоговую строку — так код становится чище и пригоднее для переиспользования (например, в функции).
- ✅ **Связь с реальными задачами:** эти навыки пригодятся для валидации кодов в боте, очистки ввода пользователя, форматирования ответов и работы с текстовыми данными в Django.
