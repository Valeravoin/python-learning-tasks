# 🧠 Модуль: Условные операторы (Conditional Operators)

Здесь собраны задачи, которые помогли мне освоить логику принятия решений в Python. Я научился использовать ветвления для проверки условий, комбинировать логические операторы и работать с математическими проверками.

---

## 📋 Решённые задачи

| Название задачи | Суть задачи | Использованные навыки |
| :--- | :--- | :--- |
| **Начало столетия** | Проверка, оканчивается ли год на два нуля | Оператор `%` (остаток от деления), базовое условие `if/else` |
| **Шахматная доска** | Определение цвета клеток | Чётность чисел, сравнение выражений, упрощение логики |
| **Girls only** | Валидация возраста и пола | Логический оператор `and`, цепочки сравнений (`10 <= age <= 15`) |
| **Римские цифры** | Конвертация чисел 1–10 | Каскадные условия `if/elif/else` |
| **Ход слона** | Проверка хода шахматной фигуры | Функция `abs()`, математическая логика диагоналей |

---

## 💪 Что я прокачал в этом модуле

- ✅ **Логика условий:** Понимание, когда использовать `if`, `elif` и `else`.
- ✅ **Математические проверки:** Работа с остатком от деления и модулем числа.
- ✅ **Цепочки сравнений:** Запись условий вида `10 <= age <= 15` вместо громоздких проверок.
- ✅ **Упрощение кода:** Умение убирать избыточные проверки (например, когда `else` покрывает все остальные случаи).
- ✅ **Валидация данных:** Проверка входных параметров на соответствие требованиям (возраст, пол).

Эти навыки — база для написания валидаторов (как в твоём чат-боте) и бизнес-логики в Django (проверка прав доступа, статусов заказа и т.д.).
